# WACKO NIGHT

Event ticketing and QR-code verification website for WACKO NIGHT.

## Event Details

- **Date:** November 7, 2026
- **Venue:** Reeplay Car Park, Under G, Ogbomoso
- **Ticket Price:** ₦3,000

## Features

- Ticket ordering and checkout through Bach.io
- Unique QR codes for tickets
- Ticket verification
- Administrative event management

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Configure the required environment variables in your local `.env` file before running the application.
